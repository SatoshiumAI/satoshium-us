# Status

## Overview

Beacon is currently under development.

The project represents the discovery layer of the Satoshium Suite and is intended to help users locate, surface, organize, and explore relevant information across the broader Satoshium ecosystem.

Beacon is currently in its foundational phase.

---

### Mission

## Current Limitations

Beacon currently:

* Does not perform automated discovery
* Does not execute queries
* Does not maintain source indexes
* Does not generate discovery results
* Does not provide signal monitoring
* Does not perform verification
* Does not establish trust

Current efforts focus on foundational architecture and documentation.

---

## Relationship to the Satoshium Suite

Beacon currently occupies the discovery role within the ecosystem.

```text
Atlas       → Data
Navigator   → Query
Certifier   → Verification
Registry    → Records
Chronicle   → History
Anchor      → Identity
Beacon      → Discovery
Attestor    → Trust
```

This structure may evolve as the ecosystem matures.

---

## Long-Term Vision

Beacon seeks to become a discovery framework capable of helping users locate meaningful information across multiple systems while preserving transparency, attribution, and source visibility.

Its purpose remains simple:

```text
Help users find the signal.
```
