Satoshium Registry Registered Items

Registered Items is the public directory of completed Satoshium Registry Entries. Each listed item resolves to a dedicated SREG directory containing the registration overview, canonical human-readable Registry Entry, machine-readable record, and repository documentation.

The directory begins with SREG-2026-0001, the first operational Registry Entry created from the certification record set for SC-CERT-2026-0001.

Directory Position

Registered Items sits between the Registry institution and each published SREG. It provides a concise public list of completed registrations while each item directory preserves the full Registry record package.

Reusable SREG Package Structure

Each published Satoshium Registry Entry (SREG) should resolve to a dedicated directory containing the same four core artifacts demonstrated by SREG-2026-0001. This structure establishes the reusable publication package for future Registry Entries while allowing each Record-Type Profile to add type-specific content within those artifacts.

SREG-YYYY-NNNN/
├── index.html
├── registry-entry.html
├── record.json
└── README.md
  • index.html — the public registration overview summarizing Registry identity, Source Authority, Record Type, status, lifecycle, provenance, Validation, Publication, relationships, and available artifacts.
  • registry-entry.html — the canonical human-readable Registry Entry containing the complete Registry-owned representation of the SREG.
  • record.json — the canonical machine-readable representation of the same SREG, governed by the SREG Base Schema and the applicable Record-Type Profile.
  • README.md — the repository-level documentation describing file responsibilities, authority boundaries, Source Record relationships, versions, Validation, Publication, Corrections, History, and maintenance requirements.
Template Principle. The four-file package defines the shared publication structure of a SREG. Record-Type Profiles may require additional fields, relationships, source artifacts, or supporting references, but they do not replace the canonical four-artifact package.

The directory name should match the permanent Registry Identifier: SREG-[YEAR]-[SEQUENCE]. The inaugural implementation, SREG-2026-0001, serves as the reference implementation for this reusable structure.

Registered Items Principle

Each registered item should provide a durable path from the public Registry directory to the canonical SREG, its machine-readable equivalent, its documentation, and the authoritative Source Record from which it was created.
