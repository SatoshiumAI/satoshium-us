## Purpose

Suite Interoperability defines how independent Satoshium institutions exchange durable references while preserving distinct canonical objects, identifiers, lifecycles, governance, provenance, and authority.

> **Reference does not transfer authority.**

Interoperability connects responsibilities.

It does not merge institutions.
