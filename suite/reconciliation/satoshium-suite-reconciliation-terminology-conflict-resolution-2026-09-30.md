## Previously Reconciled Terminology Collisions

The final review confirms closure of the principal terminology collisions addressed during Phase II:

### Validation vs Eligibility

```text
Eligibility
→ admission determination

Validation
→ determination against applicable institutional requirements
```

These remain distinct.

### Validation vs Conformance

```text
Validation
→ requirements / formal / structural determination

Conformance
→ determination against an explicit requirement set
```

These remain distinct.

### Verification vs Certification

```text
Verification
→ correspondence / evidence / reference checking

Certification
→ Certifier-governed certification determination
```

Verification does not become certification authority.

### Trust Signal vs Trust Statement

```text
Trust Signal
→ legacy / non-canonical terminology unless explicitly bounded in historical context

Trust Statement
→ canonical Attestor conclusion
```

### Beacon Discovery Signal vs Legacy Trust Signal

```text
Discovery Signal
→ canonical Beacon object

trust signal
→ legacy / non-canonical terminology
```

No collision remains.

### Decision / Outcome vs Lifecycle State

A decision or evaluation outcome does not itself constitute lifecycle state.

### Record vs Object vs Entry

```text
Canonical Object
→ Suite-wide architectural umbrella concept

Record
→ general / contextual term where appropriate

Entry
→ formal object term where institutionally defined
```

Institution-specific canonical terminology remains controlling.

### Authority vs Provenance

```text
Authority
→ who governs or is responsible

Provenance
→ where information came from and how it moved
```

Provenance does not create or transfer authority.
