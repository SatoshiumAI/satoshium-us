# 8. System Registry vs Formal Satoshium Registry

The deferred `SYS-*` question was resolved.

The reconciled distinction is:

```text
SYS-*
→ Legacy / Pre-Suite Platform System Index

SREG-*
→ Formal Satoshium Registry canonical identifier family
```

Therefore:

> **SYS ≠ SREG**

No forced migration, merger, or identifier replacement is required.

The legacy System Registry preserves historical platform identity.

The formal Satoshium Registry owns current canonical registration.
