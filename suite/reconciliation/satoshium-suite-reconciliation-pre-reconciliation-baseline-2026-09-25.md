## 1. Purpose of the Baseline

This record freezes the pre-reconciliation state of the formal Satoshium Suite.

It is a snapshot of the architecture, statuses, institutional roster, canonical responsibilities, and governing distinctions already established before reconciliation decisions are made.

This record does not resolve contradictions, harmonize terminology, redesign institutions, or settle deferred questions.

Its purpose is to preserve the starting state so that later reconciliation decisions can be distinguished from architecture that already existed.
