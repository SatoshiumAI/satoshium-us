Chronicle · Certification Events

Satoshium Chronicle Certification Events

Certification Events define the certification-related historical moments preserved by Chronicle.

Chronicle does not store certifications. Chronicle preserves the history of what happened to certifications over time.

Purpose

Certification Events provide Chronicle with a clear historical model for recording significant moments in the life of a certification.

Core Distinction

Certification records belong to Certifier. Registry entries belong to Registry. Certification events belong to Chronicle.

Historical Meaning

Events explain what happened, when it happened, and why the moment matters within the broader certification history.

Record References

Certification Events may reference Certification Packages, SCRDs, receipts, Registry Entries, public pages, attestations, anchors, or other related records.

Certification Event Types

Chronicle may preserve several certification-related event types as part of the historical record.

Certification Created → Certification Renewed → Certification Suspended → Certification Revoked → Certification Expired

Certification Created

A Certification Created event records that a new certification was produced by Certifier and became part of the certification history.

Certification Renewed

A Certification Renewed event records that an existing certification was renewed, extended, reissued, or reaffirmed according to Certifier’s rules.

Certification Suspended

A Certification Suspended event records that a certification entered a suspended condition according to Certifier’s certification status model.

Certification Revoked

A Certification Revoked event records that a certification was withdrawn, invalidated, or revoked by the system responsible for certification authority.

Certification Expired

A Certification Expired event records that a certification reached the end of its active period or was no longer current under Certifier’s rules.

Future Event Types

Future Chronicle event types may include certification updated, superseded, restored, challenged, reviewed, corrected, anchored, or attested.

What an Event Preserves

A Certification Event should preserve enough context to make the historical moment understandable without duplicating the certification record itself.

Event Type · Event Date · Source System · Related Certification · Related Registry Entry · Public References · Historical Context · Supporting Records

What an Event Does Not Do

A Certification Event does not certify, renew, suspend, revoke, or expire a certification. Those actions belong to Certifier and its certification rules.

Chronicle records that the event occurred. Chronicle does not create the authority behind the event.

Relationship to Registry

Registry catalogs certified records and their Registry lifecycle state. Chronicle preserves the historical events associated with certification activity and may reference Registry Entries to preserve discoverability.

Registry preserves the catalog entry. Chronicle preserves the event history.

Event Philosophy

Certification Events help Chronicle preserve the memory of how certifications changed over time. They provide history without replacing the systems that created, cataloged, anchored, or attested the records.
