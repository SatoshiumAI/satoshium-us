Chronicle · Publication

Publication

Chronicle Publication is the institutional act through which a reviewed Chronicle Entry Version enters public production use through its canonical public representations.

Publication occurs only after Preservation Eligibility, Entry construction, Verification, Validation, and a separate Publication Gate decision. Validation determines conformance. The Publication Gate determines whether publication is institutionally approved. Publication changes the Entry's public production state.

Publication Position

Verification → Validation → CHR-VAL-011 Publication Readiness → Publication Gate → Publication
CHR-VAL-011 tests readiness. The Publication Gate makes the institutional decision. A Validation PASS does not itself approve publication, and Publication Gate approval does not mean publication has already occurred.
Prerequisite

Preservation Eligibility

Chronicle does not publish an Entry merely because an Occurrence happened. The Occurrence must first qualify for Chronicle preservation under the approved Preservation Eligibility model.

Prerequisite

Verification

Verification reviews Chronicle's own historical representation, including identifiers, Event Date, authoritative references, Provenance, Relationships, Historical Context, and material limitations.

Decision

Publication Gate

The Publication Gate is the separate institutional decision point that determines whether a Validation-ready Entry Version is approved or withheld from publication.

Gate outcomes are procedural decisions. The Publication Gate is not a separate canonical Chronicle object and does not receive its own CHR identifier or lifecycle.

Publication States

Chronicle uses a dedicated Publication State system independent of Lifecycle State, Verification State, and Validation result.

not_published The Entry Version has not entered public production use.
pending_publication The Entry Version is awaiting or completing the publication process.
published The Entry Version is publicly released through its canonical representations.
withdrawn_from_publication The Entry Version is no longer presented as an active public production representation.
Publication State does not determine whether an Entry is historically valid, Verified, active in Lifecycle, superseded, corrected, or preserved. Those questions belong to their own Chronicle systems.
Public Representation

Canonical Human-Readable Entry

A published Chronicle Entry should resolve through a stable canonical public URI beneath the Entry collection and present the Entry's historical context, identity, authoritative references, Relationships, Provenance, review state, and publication lineage.

Canonical path pattern:
/chronicle/entries/CHR-YYYY-NNNN/
Machine Representation

Machine-Readable Entry

Published production Entries should expose the corresponding machine-readable representation where required by the governing schema and Entry package.

Human-readable and machine-readable representations describe the same canonical Chronicle Entry and must remain materially consistent.
Publication Time

published_at

When Publication State is published, Chronicle preserves the publication timestamp through published_at.

Later editorial or cross-link updates do not silently reset the original publication timestamp for the same Entry Version.

Publication Package

A published Chronicle Entry may be accompanied by durable procedural artifacts where they add institutional review value.

Canonical Entry representation:
index.html
record.json
README.md

Durable Entry-Version procedural artifacts where applicable:
CHR-YYYY-NNNN-vN-validation.md
CHR-YYYY-NNNN-vN-publication-gate.md

The Validation and Publication Gate artifacts document the review of an exact Entry Version. They do not become separate canonical Chronicle objects and do not receive independent CHR identifiers.

Change Control

Corrections and Versions

Publication does not freeze Chronicle against later correction. Material changes to Chronicle's own historical representation follow the Corrections and Versioning architecture, preserve prior substantive states, and may require Reverification, Revalidation, and a new Publication Gate decision.

Open Corrections → Open Versioning →
Withdrawal

Withdrawal from Publication

Withdrawal removes an Entry Version from active public presentation without erasing the fact that the Entry or prior publication state existed.

Withdrawal must remain historically traceable and must not silently delete material institutional history.

Authority Boundary

Publication Does Not Transfer Authority

Chronicle Publication makes Chronicle's own historical-preservation record public. It does not convert referenced Certification Packages, Registry Entries, Atlas records, or other Suite objects into Chronicle-owned authority.

Reference does not transfer authority.
Historical Continuity

Preserve Prior Public States

Material prior Entry states, Corrections, supersession relationships, and publication lineage remain preservable so later reviewers can reconstruct what Chronicle published, when, and why it changed.

Publication Method

Entry Ready for Review → Verification → Validation → CHR-VAL-011 → Publication Gate → Approve / Withhold → Publish → Maintain / Correct / Version
Validation answers whether the Entry Version conforms. The Publication Gate answers whether Chronicle approves publication. Publication records that the approved Entry Version has actually entered public production use.

Publication Principle

Validate the representation. Approve the release. Publish the Entry. Preserve the lineage.
