Chronicle Controlled Values Registry

The Controlled Values Registry defines stable vocabularies for Chronicle fields where interoperability, validation, discovery, and historical consistency require governed terms instead of uncontrolled free text.

Controlled Values should remain intentionally small, explicit, versioned, and expandable only when operational evidence demonstrates a real need.

Registry Principle

Free text for narrative meaning.
Controlled Values for repeatable institutional meaning.

A Controlled Value should exist only when stable terminology materially improves consistency, Validation, interoperability, machine readability, or public discovery.

Event Type

Classifies the qualifying Occurrence represented by the Chronicle Entry.

Certification Created Certification Renewed Certification Suspended Certification Revoked Certification Expired

These are initial operational values and should remain narrow until production use justifies additional Event Types.

Entry Status

Provides a concise operational status for the Chronicle Entry where a summary status is needed without collapsing distinct institutional state systems.

Draft Under Review Approved Published Superseded Withdrawn

Entry Status must not replace Verification State, Validation State, Publication State, Lifecycle State, or Preservation State.

Source Type

Classifies what kind of Source Chronicle is referencing.

Authoritative Record Institutional Document Web Page Repository Record Dataset Archive Statement Other

Evidence Type

Classifies the form of material that bears on a Chronicle Entry or claim.

Authoritative Evidence Documentary Evidence Repository Evidence Archival Evidence Machine-Generated Evidence Testimonial Evidence Contextual Evidence Other

Relationship Type

Defines the semantic connection between a Chronicle Entry and another Entry, supporting record, authoritative object, or approved external record.

References Related To Derived From Supersedes Superseded By Corrects Corrected By Precedes Follows

Verification State

Represents Chronicle's review state for its own historical representation.

Not Reviewed In Review Verified Verified with Limitations Unresolved

Publication State

Represents the Chronicle Entry's state within the controlled publication process.

Not Published Pending Publication Published Withdrawn from Publication

Lifecycle State

Represents the institutional lifecycle state of the Chronicle Entry itself.

Draft Active Superseded Withdrawn Preserved

Correction Type

Classifies the nature of a change made to a Chronicle-owned record.

Typographical Metadata Contextual Relationship Provenance Evidence Classification Substantive

Controlled Value Governance

Need Identified → Existing Values Reviewed → Meaning Defined → Overlap Checked → Value Approved → Versioned → Used in Schema / Validation

New values should be added only when existing terms cannot accurately represent a real operational condition.

Value Definition Rule

Every Controlled Value should have one stable institutional meaning. Similar-looking values should not be introduced when they differ only stylistically.

One value → One defined meaning

Human and Machine Forms

Chronicle may maintain a human-readable label and a machine-readable token for the same Controlled Value.

Human label → Verified with Limitations
Machine token → verified_with_limitations

The two forms must retain identical institutional meaning.

No Silent Semantic Change

An existing Controlled Value should not quietly change meaning. Material semantic changes should be handled through versioning, deprecation, replacement, or explicit migration.

Stable term → Stable meaning

Deprecation

Deprecated values should remain historically understandable. Chronicle should preserve the old value, deprecation reason, replacement value where applicable, and effective date.

Controlled Values and Validation

Future Validation should confirm that fields governed by Controlled Values use only approved terms and that the value is valid for the governing schema or Event-Type Profile.

Controlled Value Registry → Schema Constraint → Validation Rule

Free Text Boundary

Chronicle should preserve free text where historical nuance matters, including Event Representation, Historical Context, significance rationale, limitations, and explanatory notes.

Controlled Values should govern fields where consistent semantics are more important than narrative flexibility.

Narrative meaning stays expressive. Institutional state stays controlled.

Initial Registry Scope

The first registry should remain limited to vocabularies needed for near-term Chronicle operational development.

Event Type · Entry Status · Source Type · Evidence Type · Relationship Type · Verification State · Publication State · Lifecycle State · Correction Type

Additional vocabularies should be introduced only when operational need is demonstrated.

Registry Principle

Chronicle should control meaning where consistency matters and preserve flexibility where historical interpretation requires nuance.

Stable terms for interoperability. Free text for history.
