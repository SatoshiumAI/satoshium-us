# Chronicle Entry Schema — Deprecated Filename

This filename is retained for historical compatibility.

The canonical Chronicle Base Schema is now:

- `chronicle-base-schema.md`
- `chronicle-base-schema.json`

The Chronicle Entry remains the canonical Chronicle object.
The schema itself is formally named the Chronicle Base Schema.

Do not use this file as a production schema specification.

The production Base Schema is Version `1.0.0` and has now governed the first canonical
production Chronicle Entry, `CHR-2026-0001`.

This compatibility filename must remain a pointer only. It must not accumulate fields,
examples, validation rules, or a second schema definition.
