# Satoshium Atlas — Media Library

**Path:** `/atlas/media/`  
**Institution:** Satoshium Atlas  
**Surface:** Atlas Media Library  
**Status:** Current repository documentation

## Purpose

This directory contains the **Satoshium Atlas Media Library**.

The Media Library provides visual and explanatory companion surfaces that support jurisdiction familiarity, corridor interpretation, infrastructure literacy, and Atlas navigation.

The public page for this directory is:

- `index.html`

This README documents the repository role, media categories, authority boundary, and relationship of the Media Library to the broader Atlas architecture. It does not replace the public presentation in `index.html`.

## Media Library Role

The Atlas Media Library is a companion interpretation layer.

It supports understanding of Atlas jurisdiction and topology surfaces through orientation, explanation, and walkthrough media.

Conceptually:

```text
Canonical Atlas Records
        ↓
Atlas Navigation / Interpretation
        ↓
Media Companion Surfaces
```

Media supports interpretation.

It does not replace the canonical Atlas record.

### Orientation Media Library

The Orientation Media Library provides country-level and state-level orientation surfaces that support geographic, cultural, institutional, and infrastructure familiarity.

## Authority Boundary

The Media Library does not create source authority.

The governing distinction is:

```text
Canonical Atlas Package
→ Authoritative record

Atlas Media Surface
→ Contextual / explanatory companion
```

Media may explain, summarize, visualize, or orient users to Atlas material.

It should not silently redefine:

- jurisdiction records;
- evidence;
- signals;
- corridor classifications;
- certification status;
- trust conclusions; or
- other governed institutional outputs.

## Relationship to Jurisdiction Intelligence

The Media Library supports the Jurisdiction Intelligence Engine by improving familiarity with the jurisdictions and infrastructure represented in Atlas.

Jurisdiction packages remain authoritative for their own Atlas intelligence.

Media should remain traceable to those records where factual or structural claims are presented.

## Relationship to Orientation Media

Orientation Media is the current operational branch of the Media Library.

It may support:

- geographic familiarity;
- cultural context;
- institutional orientation;
- infrastructure awareness; and
- Builder Mode interpretation readiness.

Orientation media does not replace evidence or jurisdiction records.

## Relationship to Corridors

Future Corridor Explainers may provide visual or narrative interpretation of Atlas corridor structures.

Those explainers should remain downstream of the governed corridor model.

They should not create corridor membership or topology authority independently.

## Relationship to Framework Documents

Future Atlas Walkthroughs may explain framework-layer concepts.

Such media should present existing Atlas doctrine rather than create new structural rules.

Framework authority remains with the applicable Atlas framework documents.

## Trust-Related Language

The current public page refers to **trust-layer compatibility characteristics** in the context of future Jurisdiction Briefings.

That language should remain bounded to Atlas explanatory context.

It should not be treated as equivalent to:

- Attestor rule-constrained evaluation;
- an Attestor Trust Statement; or
- universal truth determination.

Where trust-related material is presented through media, it should clearly identify the underlying Atlas source context.

## Relationship to Suite Institutions

The Media Library belongs to Atlas.

Other Suite institutions may reference Atlas media where useful, but media does not transfer Atlas or Suite authority.

Examples:

- Certifier may reference Atlas records during certification.
- Registry may register governed source records or certification outputs.
- Chronicle may preserve chronology.
- Anchor may preserve Integrity References.
- Beacon may support discovery.
- Attestor may consume eligible governed inputs and issue Attestations / Trust Statements.
- Navigator may orchestrate workflows.

Media references do not alter those institutional responsibilities.

**REFERENCE DOES NOT TRANSFER AUTHORITY.**

## Repository Expectations

Changes to this directory should preserve:

1. media as a companion layer rather than source authority;
2. canonical Atlas packages as authoritative;
3. traceability from media claims to underlying Atlas records where applicable;
4. separation between media explanation and governed topology;
5. separation between Atlas trust-related interpretation and Attestor Trust Statements;
6. distinction between operational and pending media surfaces; and
7. consistency with Atlas navigation and framework doctrine.

Changes that would redefine jurisdiction authority, corridor authority, trust semantics, or cross-Suite institutional boundaries require governed architectural review rather than a documentation-only edit.

## Governing Principle

**Atlas media extends understanding of jurisdiction intelligence without replacing the canonical records that define it.**
