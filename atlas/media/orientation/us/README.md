# Satoshium Atlas — United States Orientation Media

**Path:** `/atlas/media/orientation/us/`  
**Institution:** Satoshium Atlas  
**Surface:** United States Orientation Media  
**Status:** Current repository documentation

## Purpose

This directory contains the **United States Orientation Media** surface for Satoshium Atlas.

It provides the national-level media overview for the U.S. Atlas orientation layer and routes visitors into the dedicated state-level orientation directory.

The public page for this directory is:

- `index.html`

This README documents the repository role, national-vs-state media boundary, authority discipline, and relationship of this surface to the broader Atlas architecture. It does not replace the public presentation in `index.html`.

## United States Orientation Role

The United States Orientation Media page is the national overview layer for Atlas media orientation.

It provides:

- U.S.-level jurisdiction context;
- infrastructure familiarity;
- national orientation media;
- visual overview material; and
- routing into the dedicated state orientation directory.

Conceptually:

```text
Atlas Orientation Media
        ↓
United States Orientation Media
        ↓
U.S. States Orientation Directory
        ↓
Individual State Orientation Surfaces
```

The national page provides context.

It does not replace the underlying U.S. jurisdiction package or individual state records.

## National Overview Surface

The current page includes:

- a United States orientation video;
- a visual overview image;
- national-level jurisdiction context; and
- links into the U.S. States Orientation Media directory.

This surface should remain focused on national orientation rather than duplicating the full state-level routing structure.

## State Orientation Routing

State-by-state routing is centralized under:

```text
/atlas/media/orientation/us/states/
```

That directory is the appropriate place for individual state media navigation.

The United States page should therefore remain the national overview layer above that directory.

## Current State Media Maturity

The public page notes that California currently has a completed dedicated state media page and that remaining states may route through temporary placeholders until their individual media surfaces are created.

That distinction should remain explicit.

A state orientation placeholder does not imply that the underlying canonical Atlas state package is incomplete.

Media maturity and jurisdiction-package maturity are separate concepts.

## Authority Boundary

The United States Orientation Media surface is contextual.

Canonical state and U.S. jurisdiction packages remain authoritative.

The governing distinction is:

```text
Canonical U.S. / State Jurisdiction Package
→ Authoritative Atlas record

United States Orientation Media
→ Contextual companion surface
```

Media should not independently redefine:

- evidence;
- signals;
- trust-related dimensions;
- corridor classifications;
- jurisdiction conclusions;
- certification status; or
- downstream Suite institutional objects.

## Relationship to the U.S. Jurisdiction Package

The United States jurisdiction package remains the authoritative national Atlas record structure.

This media surface provides orientation context alongside that package.

Navigation between the two does not transfer authority.

## Relationship to State Packages

State media surfaces may provide cultural, geographic, institutional, or infrastructure familiarity.

The corresponding canonical state package remains authoritative for Atlas state-level jurisdiction intelligence.

## Relationship to Corridors

The public page references future corridor interpretation.

Orientation media may support corridor understanding, but it should not independently establish corridor membership, corridor classification, or topology authority.

Corridor structures remain governed by Atlas corridor architecture and evidence-derived records.

## Trust-Related Context

If state or national orientation media refers to Atlas trust-related material, that terminology remains bounded to Atlas.

Atlas trust-related dimensions are not Attestor Trust Statements.

Orientation media should not imply independent trust evaluation.

## Relationship to Suite Institutions

The United States Orientation Media surface belongs to Atlas.

Other Suite institutions may reference Atlas materials under their own governed responsibilities, but media does not transfer authority.

Examples include:

- Certifier may certify eligible Atlas subjects.
- Registry may create governed Registry records.
- Chronicle may preserve chronology.
- Anchor may preserve Integrity References.
- Beacon may publish Discovery Signals / Discovery Metadata.
- Attestor may consume eligible governed inputs and issue Attestations / Trust Statements.
- Navigator may define or orchestrate workflows.

**REFERENCE DOES NOT TRANSFER AUTHORITY.**

## Expansion Model

The current structure supports future state-specific media surfaces without duplicating the state list on the national overview page.

The national surface may expand with additional U.S.-level orientation material, provided that state-by-state routing remains centralized in the dedicated States directory.

## Repository Expectations

Changes to this directory should preserve:

1. the page as the national U.S. media overview;
2. separation between national and state-level orientation routing;
3. canonical U.S. and state jurisdiction packages as authoritative;
4. distinction between media maturity and jurisdiction-package maturity;
5. corridor interpretation without independent topology authority;
6. separation between Atlas trust-related context and Attestor Trust Statements;
7. stable state-directory routing; and
8. compatibility with future media expansion.

Changes that would redefine jurisdiction authority, corridor authority, trust semantics, or cross-Suite institutional boundaries require governed architectural review rather than a documentation-only edit.

## Governing Principle

**The United States Orientation Media surface provides national context and routes visitors to state media while leaving canonical Atlas jurisdiction packages authoritative.**
