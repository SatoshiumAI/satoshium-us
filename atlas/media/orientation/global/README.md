# Satoshium Atlas — Global Orientation Media

**Path:** `/atlas/media/orientation/global/`  
**Institution:** Satoshium Atlas  
**Surface:** Global Orientation Media  
**Status:** Current repository documentation

## Purpose

This directory contains the **Global Orientation Media** surface for Satoshium Atlas.

It provides country-level orientation media supporting jurisdiction familiarity, cultural context, infrastructure awareness, and future corridor interpretation alongside the canonical Atlas country packages.

The public page for this directory is:

- `index.html`

This README documents the repository role, country-routing model, media boundary, and relationship of this surface to the broader Atlas architecture. It does not replace the public presentation in `index.html`.

## Global Orientation Role

Global Orientation Media is a companion layer to Atlas country packages.

Conceptually:

```text
Canonical Atlas Country Package
        ↓
Global Orientation Media
        ↓
Jurisdiction Familiarity / Context
```

Media helps visitors understand a jurisdiction.

It does not replace the canonical country record.

## Current Country Routing

The current public page provides country-level media routing through:

```text
/atlas/media/orientation/global/countries/
```

Each listed country routes to its dedicated orientation-media page.

The page currently distinguishes completed orientation surfaces from placeholder or future media surfaces.

## Completion and Maturity

A completed orientation-media page indicates that the media companion surface has been published for that country.

It does not, by itself, establish:

- canonical completeness of the underlying country package;
- certification status;
- Registry status;
- Attestor status;
- publication status of unrelated Atlas files; or
- equal maturity across all country packages.

Media maturity and jurisdiction-package maturity remain separate concepts.

## Authority Boundary

The public page correctly preserves the distinction between media and canonical records.

Global Orientation Media must not replace or redefine:

- canonical country packages;
- evidence;
- signals;
- trust dimensions;
- profiles;
- Builder Mode files;
- metadata;
- change logs;
- corridor classifications; or
- downstream Suite institutional objects.

The governing distinction is:

```text
Canonical Country Package
→ Authoritative Atlas jurisdiction record

Global Orientation Media
→ Companion context and familiarity
```

## Relationship to the Jurisdiction Intelligence Engine

The Global Orientation Media surface is intentionally separate from the Jurisdiction Intelligence Engine.

Visitors may begin with media context and then move into the canonical country package for structured Atlas interpretation.

The two surfaces are complementary:

```text
Orientation Media
→ contextual familiarity

Jurisdiction Intelligence Engine
→ canonical jurisdiction navigation
```

## Relationship to Country Packages

Each country orientation surface should remain aligned with the corresponding Atlas country package.

Where media makes factual, institutional, geographic, or infrastructure claims, the underlying country package should remain the authoritative source context.

## Relationship to Evidence and Signals

Orientation media may summarize or explain evidence-derived Atlas material.

It should not independently create:

- evidence;
- signals;
- jurisdiction conclusions; or
- topology classifications.

Evidence and signal provenance remain governed by the Atlas jurisdiction package.

## Trust-Related Context

The public page refers to canonical country package **trust dimensions**.

That terminology remains Atlas-specific.

Atlas trust dimensions are not Attestor Trust Statements.

Orientation media should not imply independent trust evaluation or Attestor conclusions.

## Relationship to Corridors

Global Orientation Media may eventually support regional orientation pages, corridor playlists, or corridor-related explainers.

Those media surfaces should remain downstream of the governed Atlas corridor model.

They should not independently establish corridor membership or topology authority.

## Relationship to Suite Institutions

Global Orientation Media belongs to Atlas.

Other Suite institutions may reference Atlas materials under their own governed roles, but media does not transfer authority.

Examples include:

- Certifier may certify eligible Atlas subjects.
- Registry may create governed Registry records.
- Chronicle may preserve chronology.
- Anchor may preserve Integrity References.
- Beacon may publish Discovery Signals / Discovery Metadata.
- Attestor may consume eligible governed inputs and issue Attestations / Trust Statements.
- Navigator may define or orchestrate workflows.

**REFERENCE DOES NOT TRANSFER AUTHORITY.**

## Expansion Model

The current page is designed to support:

- additional country media pages;
- regional orientation pages;
- corridor playlists; and
- subnational media surfaces.

These are expansion capabilities, not statements that all such surfaces are already operational.

## Path and Link Discipline

Country orientation links should use stable, canonical slugs matching the corresponding Atlas country naming conventions.

Route corrections should be treated as technical maintenance when they clearly resolve a malformed or inconsistent path without changing architecture.

## Repository Expectations

Changes to this directory should preserve:

1. media as a companion layer rather than source authority;
2. canonical country packages as authoritative;
3. separation between media maturity and jurisdiction-package maturity;
4. country-link stability;
5. evidence and signal provenance;
6. separation between Atlas trust dimensions and Attestor Trust Statements;
7. corridor interpretation without independent topology authority; and
8. compatibility with future global media expansion.

Changes that would redefine jurisdiction authority, trust semantics, corridor authority, or cross-Suite institutional boundaries require governed architectural review rather than a documentation-only edit.

## Governing Principle

**Global Orientation Media provides jurisdiction context without replacing the canonical Atlas country records that define the jurisdiction.**
