# Satoshium Atlas — Orientation Media Library

**Path:** `/atlas/media/orientation/`  
**Institution:** Satoshium Atlas  
**Surface:** Orientation Media Library  
**Status:** Current repository documentation

## Purpose

This directory contains the **Satoshium Atlas Orientation Media Library**.

The Orientation Media Library provides jurisdiction-familiarity media supporting both U.S. state packages and global country packages.

The public page for this directory is:

- `index.html`

This README documents the repository role, orientation-media structure, authority boundary, and relationship of this surface to the broader Atlas architecture. It does not replace the public presentation in `index.html`.

## Orientation Media Role

Orientation Media is an Atlas companion surface.

It provides geographic, cultural, institutional, and infrastructure familiarity that helps visitors understand the jurisdictions represented in Atlas.

Conceptually:

```text
Canonical Atlas Jurisdiction Package
        ↓
Orientation / Familiarity Layer
        ↓
Improved Context for Review and Navigation
```

Orientation media supports understanding.

It does not replace the canonical jurisdiction record.

## Current Orientation Branches

The current public page exposes two primary branches.

### United States Orientation Library

The U.S. Orientation Library provides state-level media aligned with the completed United States Atlas baseline.

It supports:

- state-by-state orientation;
- familiarity with jurisdiction context;
- parallel navigation alongside canonical state packages; and
- readiness for corridor interpretation.

### Global Orientation Library

The Global Orientation Library provides country-level orientation media supporting Atlas international expansion.

It supports:

- country-by-country orientation routing;
- global jurisdiction familiarity; and
- future regional media overlays.

## Authority Boundary

Orientation media is contextual.

Canonical Atlas files remain authoritative.

The governing distinction is:

```text
Canonical Jurisdiction Package
→ Authoritative Atlas record

Orientation Media
→ Companion context and familiarity
```

Orientation media should not independently establish or redefine:

- jurisdiction facts;
- evidence;
- signals;
- trust-related dimensions;
- corridor classifications;
- certification status;
- Suite institutional outputs; or
- canonical record identity.

## Relationship to the Jurisdiction Intelligence Engine

Orientation Media supports the Jurisdiction Intelligence Engine by helping visitors understand the jurisdictions they are navigating.

The JIE remains the jurisdiction-navigation layer.

Orientation Media remains a companion interpretation layer.

Neither replaces the underlying jurisdiction package.

## Relationship to U.S. State Packages

The U.S. Orientation Library runs in parallel with the state-package structure.

A state orientation surface may help establish geographic, cultural, institutional, or infrastructure familiarity.

The corresponding Atlas state package remains authoritative for the state-level jurisdiction intelligence record.

## Relationship to Global Country Packages

The Global Orientation Library runs in parallel with Atlas country packages.

A country orientation surface may provide useful context, but the corresponding country package remains authoritative for Atlas jurisdiction intelligence.

The maturity of a media surface should not be treated as evidence of the maturity, completeness, certification state, or publication state of the underlying country package.

## Relationship to Corridors

Orientation media may support corridor interpretation readiness.

It should not create corridor membership, topology classifications, or corridor authority independently.

Corridor authority remains with the applicable Atlas corridor architecture and evidence-derived records.

## Trust-Related Context

Orientation media should avoid implying independent trust conclusions.

Where trust-related Atlas terminology is discussed, it should remain bounded to the underlying Atlas record context.

Atlas trust-related dimensions are not Attestor Trust Statements.

## Relationship to Suite Institutions

The Orientation Media Library belongs to Atlas.

Other Suite institutions may reference Atlas materials under their own governed responsibilities, but orientation media does not transfer authority.

Examples include:

- Certifier may certify eligible Atlas subjects.
- Registry may create governed Registry records.
- Chronicle may preserve chronology.
- Anchor may preserve Integrity References.
- Beacon may publish Discovery Signals / Discovery Metadata.
- Attestor may consume eligible governed inputs and issue Attestations / Trust Statements.
- Navigator may define or orchestrate workflows.

**REFERENCE DOES NOT TRANSFER AUTHORITY.**

## Expansion Model

The public page describes the Global Orientation Library as supporting continued global Atlas expansion.

That should be treated as an expansion path rather than a statement that every future international media surface is already operational or complete.

Regional media overlays may be added later where Atlas formally establishes them.

## Repository Expectations

Changes to this directory should preserve:

1. orientation media as a companion layer rather than source authority;
2. canonical jurisdiction packages as authoritative;
3. clear separation between U.S. and global orientation branches;
4. traceability between media and the jurisdictions it supports;
5. corridor interpretation without independent topology authority;
6. separation between Atlas trust-related context and Attestor Trust Statements;
7. distinction between current and future media surfaces; and
8. stable navigation as Atlas media expands.

Changes that would redefine jurisdiction authority, corridor authority, trust semantics, or cross-Suite institutional boundaries require governed architectural review rather than a documentation-only edit.

## Governing Principle

**Orientation media improves jurisdiction familiarity without replacing the canonical Atlas records that define the jurisdiction.**
