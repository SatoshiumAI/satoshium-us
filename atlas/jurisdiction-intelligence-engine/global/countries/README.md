# Satoshium Atlas — Global Country Packages

**Path:** `/atlas/jurisdiction-intelligence-engine/global/countries/`  
**Institution:** Satoshium Atlas  
**Surface:** Global Country Package Index  
**Status:** Current repository documentation

## Purpose

This directory contains the **Global Country Package Index** for the Satoshium Atlas Jurisdiction Intelligence Engine.

It provides navigation into Atlas country-level jurisdiction packages outside the United States.

The public page for this directory is:

- `index.html`

This README documents the repository role, navigation boundary, and relationship of the Global Country Package Index to the broader Atlas architecture. It does not replace the public presentation in `index.html`.

## Index Role

The Global Country Package Index is a navigation surface.

It organizes entry points into country-level Atlas jurisdiction packages and supports the international expansion path of the Jurisdiction Intelligence Engine.

Conceptually:

```text
Satoshium Atlas
        ↓
Jurisdiction Intelligence Engine
        ↓
Global
        ↓
Country Package Index
        ↓
Individual Country Packages
```

The index does not itself become the authoritative source for each country record.

It routes to those records.

## Country Package Boundary

Each country package remains an Atlas-owned jurisdiction structure.

The index should preserve the distinction between:

- country navigation;
- the country record itself;
- supporting evidence;
- metadata;
- signals;
- trust-related dimensions;
- corridor relationships; and
- downstream Suite institutional records.

Navigation is not authority.

## Relationship to the Jurisdiction Intelligence Engine

The Global Country Package Index is part of the Jurisdiction Intelligence Engine.

The JIE provides the durable navigation layer for jurisdiction packages.

This index specifically provides the international country-level branch of that navigation structure.

## Relationship to Atlas

Atlas remains authoritative for:

- country-level jurisdiction intelligence;
- country-package structure;
- Atlas-owned metadata;
- Atlas signals;
- Atlas trust-related dimensions;
- Atlas corridor relationships; and
- Atlas change history.

This index merely exposes those packages through a common navigation surface.

## Relationship to Evidence

Country packages may contain or reference evidence supporting their Atlas claims and structural interpretation.

Evidence should remain attributable to the underlying country package.

The index should not transform referenced evidence into independent authority.

## Relationship to Signals

Country signals remain derived from the applicable Atlas evidence and jurisdiction context.

The Global Country Package Index may provide navigation to packages containing signals, but it should not independently create or redefine those signals.

## Trust-Related Context

Where country packages include Atlas trust-related dimensions, those dimensions remain Atlas terminology.

They are not equivalent to Attestor Trust Statements.

The following distinction should remain explicit:

```text
Atlas Trust-Related Context
≠
Attestor Trust Statement
```

## Relationship to Corridors

Country packages may participate in Atlas corridor or other cross-jurisdiction topology structures where applicable.

Corridor participation provides structural context.

It does not replace the country package as the jurisdiction-level record.

## Relationship to Suite Institutions

The Global Country Package Index belongs to Atlas.

Other Suite institutions may reference country records or Atlas-derived outputs according to their own governed roles.

Examples include:

- Certifier may certify eligible Atlas subjects.
- Registry may create a Registry Entry / SREG referencing an Atlas or certification object.
- Chronicle may preserve governed chronology.
- Anchor may preserve an Integrity Reference.
- Beacon may publish Discovery Signals / Discovery Metadata.
- Attestor may consume eligible governed inputs and issue Attestations / Trust Statements.
- Navigator may define or orchestrate workflows.

**REFERENCE DOES NOT TRANSFER AUTHORITY.**

## Construction and Maturity Status

The public page states that many global country packages are currently under structured construction.

That statement should be interpreted as a package-maturity note, not as a change to the operational status of Atlas itself.

Country-package maturity may vary.

Where maturity or publication state matters, the applicable country package should provide the authoritative current state.

## URL and Navigation Stability

The index should preserve stable, predictable country paths.

Stable paths support:

- durable public references;
- repository consistency;
- historical continuity;
- machine-readable exports;
- cross-document linking; and
- future map or UI layers.

## Repository Expectations

Changes to this directory should preserve:

1. the index as a navigation surface rather than source authority;
2. country packages as Atlas-owned jurisdiction records;
3. evidence and signal provenance;
4. separation between Atlas trust-related dimensions and Attestor Trust Statements;
5. stable country URLs;
6. corridor relationships without authority transfer;
7. maturity/status distinctions among country packages; and
8. compatibility with future global Atlas expansion.

Changes that would redefine country-package authority, canonical jurisdiction structure, trust semantics, or cross-Suite object relationships require governed architectural review rather than a documentation-only edit.

## Governing Principle

**The Global Country Package Index organizes access to international Atlas jurisdiction records without replacing the authority or state of the country packages it exposes.**
