# Russia — Trust Dimensions

## Trust Dimensions Scope

This file derives strictly from `evidence.md` for Russia.

Trust dimensions describe observable continuity relationships only. They do not assign trust scores, readiness levels, rankings, certifications, deployment meaning, or Atlas surface assignments.

This layer remains operational, evidence-bound, infrastructure-oriented, and renderer-safe. It does not create geopolitical, war/conflict, sanctions, regime, surveillance, censorship, cyber-threat, energy-power, resource-export, great-power, Eurasian-strategy, or economic-power interpretation.

Bounded observability is preserved throughout.
