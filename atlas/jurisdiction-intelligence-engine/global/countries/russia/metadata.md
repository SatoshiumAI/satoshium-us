# Russia — Metadata

## Metadata Scope

This metadata layer derives strictly from:

* evidence.md
* signals.md
* trust-dimensions.md

The purpose of this layer is to provide a machine-readable characterization of observable continuity, interoperability, coordination, and observability characteristics visible within Russia.

This layer:

* does not assign scores
* does not assign rankings
* does not assign readiness
* does not assign Atlas surfaces
* does not create geopolitical interpretation
* does not create war/conflict interpretation
* does not create sanctions interpretation
* does not create regime interpretation
* does not create surveillance interpretation
* does not create censorship interpretation
* does not create economic-power interpretation

Bounded observability remains preserved.
