# Comparison Template

**A standardized template for comparative analysis within Navigator.**

This template provides a consistent framework for comparing jurisdictions, records, signals, trust dimensions, historical information, and related resources within Satoshium Navigator.

The Comparison Template is intended to improve consistency, transparency, traceability, and usability across comparison activities.
