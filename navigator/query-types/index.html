Navigator · Query Classification Framework

Query Types

Query Types define the primary categories of information requests supported by Satoshium Navigator.

Different questions require different retrieval, comparison, filtering, and analytical approaches. Query Types provide the structure that helps Navigator organize those activities.

Purpose of Query Types

● Core Framework

Structured Exploration

Query Types organize information requests into consistent categories that improve retrieval, analysis, and presentation.

● Discovery Framework

Efficient Navigation

Different query types help users move more efficiently from questions to relevant information and outputs.

Query Type Categories

Jurisdiction Queries

Focused on countries, states, provinces, territories, regions, and related jurisdictional records.

Comparison Queries

Designed to evaluate similarities, differences, relationships, and contextual distinctions between multiple subjects.

Signal Queries

Retrieve information associated with observable indicators, trends, measurements, classifications, and analytical categories.

Trust Dimension Queries

Focus on characteristics such as stability, transparency, predictability, accessibility, and consistency.

Historical Queries

Explore timelines, change records, historical developments, Chronicle entries, and contextual history.

Research Queries

Combine multiple information categories, records, filters, and analytical frameworks to support broader investigation.

Filter-Based Queries

Apply specific criteria to refine retrieved information according to objectives, categories, or areas of interest.

Custom Queries

User-defined requests that combine multiple query types into specialized exploration and analysis workflows.

Query Characteristics

Structured

Queries follow defined frameworks that improve consistency, usability, and retrieval quality.

Traceable

Query results maintain visibility into supporting records, references, and information sources.

Flexible

Query structures can support simple information requests or complex analytical investigations.

Filterable

Query results may be refined using jurisdiction, signal, time, category, or custom filters.

Comparable

Many query types support side-by-side evaluation and comparative analysis.

Expandable

Queries may evolve as additional systems, records, and capabilities become available.

Relationship to Navigator

Query Types provide the organizational framework that helps Navigator determine how information should be retrieved, filtered, compared, analyzed, and presented.

By classifying information requests into structured categories, Navigator can provide more consistent and meaningful exploration experiences.

Relationship to Atlas

Many Query Types operate on information originating from Atlas. Jurisdiction records, signals, evidence, metadata, trust dimensions, and related resources may be accessed through different query classifications.

Query Types help organize how Atlas information is retrieved without altering Atlas as the underlying source repository.

Disclaimer

Query Types are organizational frameworks intended to improve information retrieval, exploration, comparison, and understanding.

Classification of a query does not determine the accuracy, truthfulness, or completeness of retrieved information.

Users remain responsible for evaluating information, reviewing supporting records, and drawing their own conclusions.
