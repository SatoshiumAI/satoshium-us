Attestor · Templates

Templates

This area preserves candidate authoring formats derived from Attestor's foundational architecture. Templates assist creation; they do not independently define canonical objects or technical standards.

Canonical responsibility: Attestor → Trust Statement
Governing principle: Reference does not transfer authority.

Attestation

Candidate authoring profile for a governed, attributable assertion with scope, provenance, supporting references, limitations, and traceability.

Evidence Attestation

Candidate specialization for bounded assertions concerning Evidence. Exact Evidence relationships remain unresolved.

Source Attestation

Candidate specialization for source/provenance assertions and source relationships.

Correction

Candidate governed-change format. Correction is not yet established as a separate Attestor object class.

Trust Signal — Legacy

Retained for design history only. Trust Signal is not a canonical Attestor object; useful concepts may later inform evaluation context.

Operational Templates — Deferred

Final field sets, identifiers, controlled values, lifecycle behavior, validation, and production formats depend upon Advanced Architecture.

Architecture Before Templates

Architecture → Schema/Profile → Template → Governed Instance

Templates should implement decisions already made elsewhere. They should never become a back door through which provisional June-era concepts become canonical architecture.
