Attestor · Templates

Templates

Attestor templates are governed authoring aids derived from adopted architecture and applicable schemas/profiles. They help create reviewable Attestor objects and governed changes without independently defining institutional architecture.

Canonical responsibility: Attestor → Trust Statement
Template rule: Architecture → Schema/Profile → Template → Governed Instance
Governing principle: Reference does not transfer authority.

Attestation

Core authoring template for a canonical governed, attributable assertion using the adopted ATT-YYYY-NNNN identity family and established Attestor structural concepts.

Evidence Attestation Profile

Specialized authoring profile for the adopted evidence Attestation Type. Evidence remains input/context for evaluation rather than automatic proof.

Source / Provenance Attestation Profile

Specialized authoring profile for the adopted source-provenance Attestation Type, preserving source identity, provenance, state, and authority context.

Trust Statement

Authoring template for Attestor's canonical institutional output using the TRST-YYYY-NNNN identifier family and a bounded Attestor conclusion.

Governed Correction / Change

Operational change worksheet for Attestor-owned objects. Correction is governed through Lifecycle and Versioning and is not established as a separate canonical object class.

Trust Signal — Legacy

Historical design artifact only. Trust Signal is not a canonical Attestor object or operational template; useful context belongs in governed evaluation structures.

Architecture Before Templates

Architecture → Schema/Profile → Template → Governed Instance

Templates implement decisions made by Attestor architecture. Controlled values, canonical identity, authority boundaries, provenance, lifecycle, versioning, evaluation, validation, conformance, and publication remain governed by their respective Attestor specifications.
