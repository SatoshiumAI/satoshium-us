Attestor · Operational Schemas

Schemas

This area defines the structural schema layer through which adopted Attestor architecture is expressed for implementation, authoring, executable validation, and production use. The canonical ATT/TRST object contracts have now been exercised by the first controlled production operation.

Canonical responsibility: Attestor → Trust Statement
Schema hierarchy: Architecture → Schema/Profile → Template → Governed Instance
Governing principle: Reference does not transfer authority.

Attestation Schema

Structural schema for a canonical governed, attributable Attestation using the ATT-YYYY-NNNN identifier family.

Trust Statement Schema

Structural schema for Attestor's canonical institutional output: a governed, attributable, bounded conclusion using the TRST-YYYY-NNNN identifier family.

Evidence Attestation Profile

Specialized schema profile for the adopted evidence Attestation Type. Evidence informs evaluation but does not automatically establish proof or a Trust Statement.

Source / Provenance Attestation Profile

Specialized schema profile for the adopted source-provenance Attestation Type, preserving provenance, relevant source state, and authority context.

Correction / Change Profile

Governed change structure used with Lifecycle and Versioning. Correction does not become a separate canonical object class merely because a change profile exists.

Trust Signal — Legacy

Historical design artifact only. Trust Signal is not a canonical Attestor object, identifier family, score, reputation mechanism, or production schema.

Schema and Validation Boundary

Schemas define the canonical structural contract. Validation tests applicable normative requirements against an object and its execution context. Production use demonstrated both layers without collapsing them: schema representation did not itself determine Eligibility, Evaluation Outcome, Conformance, Publication, or truth.

Schema → Structural contract
Validation → Applicable rule testing
Conformance → Separate determination
Evaluation → Separate institutional act

Schema Conformance / Validity ≠ Evaluation Outcome
Valid ≠ Published
Schema Representation ≠ Universal Truth
