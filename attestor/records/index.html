Attestor · Records

Records

This area documents governed reference profiles through which Attestor may relate eligible source objects to Attestations, Rule-Constrained Evaluation, and Trust Statements.

These profiles do not create a second Attestor record system. Source objects remain governed by their originating institutions or external authorities.

Canonical responsibility: Attestor → Trust Statement
Governing principle: Reference does not transfer authority.

External Sources

Eligible governed information originating outside Satoshium, with external authority and provenance preserved.

Architectural Status

Reference-profile architecture is established. Eligibility, authority, provenance, relationships, source-state handling, lifecycle triggers, and validation now follow the adopted Attestor Advanced Architecture.

Reference Model

Source Object → Governed Reference → Attestation / Evaluation → Trust Statement

A source object does not become an Attestor-owned record merely because Attestor references it. The route /attestor/records/ is retained, while the documents within it are governed Reference Profiles.
