# Atlas Reference Profile — Advanced Architecture

## Purpose
Defines how Attestor may reference **Atlas Authoritative Intelligence** when relevant and eligible for a bounded Attestor evaluation.

## Canonical Boundary
**Atlas → Authoritative Intelligence**  
**Attestor → Trust Statement**

Attestor does not duplicate or replace Atlas authority.

## Governed Reference Context
Preserve, as applicable:
- Atlas object identifier or resolvable reference;
- relevant object/type context;
- version or source state;
- provenance;
- relevant time/state at evaluation;
- scope and relevance;
- relationship to the Attestation/evaluation;
- material limitations; and
- Atlas authority context (`Suite-source`).

## Eligibility
Atlas status or authority does not automatically establish eligibility.

`Atlas Reference + Evaluation Purpose + Scope + Provenance + State + Relationship + Rules → Eligibility Determination`

## Change
Material Atlas source-state change may trigger Attestor review. It does not silently rewrite the historical evaluation basis.

## Governing Principle
> **Reference does not transfer authority.**

## Status
Advanced governed Reference Profile.
