# Chronicle Reference Profile

## Purpose
Describes how Attestor may reference a **Chronicle Entry** when historical context is relevant and eligible for an Attestation or Trust Statement evaluation.

## Canonical Boundary
**Chronicle → Chronicle Entry**  
**Attestor → Trust Statement**

Chronicle remains authoritative for its preserved historical entry. Attestor does not rewrite Chronicle history.

## Historical Context
A Chronicle reference may provide relevant event, sequence, correction, provenance, or other historical context. Historical context does not automatically determine the Attestor conclusion.

## Reference Requirements
A Chronicle reference should preserve enough information to identify the Chronicle Entry, relevant event/state, provenance, temporal context, scope and relevance, relationship to the Attestation/evaluation, and Chronicle authority.

## Current and Historical State
Attestor should distinguish the historical source state considered during evaluation from later changes where material.

## Governing Principle
> **Reference does not transfer authority.**

## Status
Foundational reference profile. Exact fields, eligibility, temporal handling, validation, and schemas remain advanced architecture.
