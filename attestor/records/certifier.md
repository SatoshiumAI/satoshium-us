# Certifier Reference Profile — Advanced Architecture

## Purpose
Defines how Attestor may reference a **Certifier Certification Package** or other currently recognized Certifier-governed certification context when relevant and eligible.

## Canonical Boundary
**Certifier → Certification Package**  
**Attestor → Trust Statement**

Certification remains within Certifier authority.

## Governed Reference Context
Preserve, as applicable:
- Certification Package identifier/reference;
- certification context and relevant status/state;
- version where applicable;
- provenance;
- relevant time/state at evaluation;
- scope and relevance;
- relationship to the Attestation/evaluation;
- material limitations; and
- Certifier authority context (`Suite-source`).

## No Automatic Trust Effect
Certification does not automatically become an Attestation, Trust Statement, Evaluation Outcome, score, or favorable conclusion.

## Eligibility
A recognized Certifier object must still be eligible for the particular evaluation.

## Change
Material certification-state change may trigger Attestor review.

## Governing Principle
> **Reference does not transfer authority.**

## Status
Advanced governed Reference Profile.
