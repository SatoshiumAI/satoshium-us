Anchor · Verification

Satoshium Anchor · Verification

Verification determines whether a reviewed representation reproduces the integrity evidence preserved by an Anchor Integrity Reference.

Verification evaluates integrity consistency only. It does not determine substantive truth, certification validity, historical meaning, reputation, or trust.

Verification Principle

Reproduce faithfully. Compare precisely. Report only what the evidence proves.

Verification Result

The first production-frozen Verification Result is:

match means that comparison was successfully reached and the observed integrity material agrees with the expected integrity material preserved by Anchor.

Production-Frozen

Initial Verification

Initial Verification confirms that a newly constructed Integrity Reference correctly represents the intended Canonical Representation and Integrity Value before publication.

Reverification

Reverification tests later integrity consistency using the same governed representation, boundary, canonicalization, method, and comparison semantics preserved by the record.

Verification vs. Validation

Validation
→ does the Anchor record conform to institutional and schema requirements?

Verification
→ does the reviewed representation reproduce the preserved integrity evidence?

These functions are related but not interchangeable.

What Verification Does Not Prove

Verification Result ≠ Certification
Verification Result ≠ Truth Determination
Verification Result ≠ Reputation
Verification Result ≠ Trust Judgment

A successful integrity comparison establishes consistency between the reviewed representation and the integrity evidence Anchor preserves. It does not expand Anchor's institutional authority.

Mismatch and Non-Comparison Outcomes

A mismatch indicates that observed integrity material does not agree with the expected integrity material. It does not, by itself, identify the cause.

Other non-comparison outcomes may eventually be governed where a valid comparison cannot be reached. Those additional machine tokens remain intentionally unfrozen until production requires them.

Authority Boundary

Verification does not transfer Source authority to Anchor.

Source Institution
→ remains authoritative for the Source Artifact

Anchor
→ remains authoritative for the Integrity Reference and recorded Verification Result

Reference does not transfer authority.
