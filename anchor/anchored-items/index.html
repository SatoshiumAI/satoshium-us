Anchored Items

Anchored Items are the production packages associated with assigned Satoshium Anchor Integrity References.

This directory may contain both pre-publication candidates and published Anchor records. Inclusion here does not itself mean that an Integrity Reference has passed the Publication Gate.

Directory Role

/anchor/anchored-items/
→ production package home

/anchor/integrity-references/
→ published Integrity Reference index

Anchored Items preserve the complete record-specific production package. The published Integrity Reference index should list only records that have completed Validation, Verification, Publication Gate approval, and publication.
