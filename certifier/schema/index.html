Certifier · Schema

Schema

Schema defines the structured formats used by Satoshium Certifier to represent Certification Packages, generated artifacts, evidence inventories, certified records, and Suite-ready references.

Suite Standards define the meaning of certification. Suite Methodology defines the process. Certifier schemas preserve the operational records produced when that process is executed.

Suite Standards → Suite Methodology → Operations Toolkit →

Certification Package Schema

Canonical Source

The Certification Package schema defines the primary certification object, including the certification subject, scope, governing standards, applicable methodology, evidence inventory, evaluation, decision, history, and generated outputs.

SCRD JSON Schema

Certified Record

The SCRD JSON schema defines the machine-readable certified record generated from the canonical Certification Package for public indexing, Registry integration, future APIs, and long-term interoperability.

Evidence Inventory Schema

SEV Support

Evidence schemas organize the factual materials reviewed during certification, including source references, evidence types, traceability notes, review status, integrity references, and mapped standards support.

Generated Artifact Fields

Derived Outputs

Schema conventions support generated artifacts including SCPR reports, SCR receipts, SCRD HTML records, SCRD JSON records, evidence maps, and release readiness checklists.

Suite Reference Stubs

Integration Ready

Structured reference stubs prepare certification records for Registry cataloging, Chronicle preservation, Anchor integrity references, and Attestor verification support.

Versioning & Portability

Durable Records

Schemas should be versioned so historical certification records remain understandable even when newer schema versions, stronger validation rules, or additional Suite integrations are introduced.

Schema Flow

Certifier schema begins with the Certification Package as the canonical source object. Generated artifacts and Suite references should derive from that source rather than becoming independent certification decisions.

Schema does not certify by itself. It preserves the structure of a certification decision made through Suite Standards, Suite Methodology, evidence review, and Certifier execution.

Schema Role

Schema is the structural record layer of Certifier. Documentation explains the system, reports preserve reasoning, receipts summarize outcomes, and schema gives certification records a durable machine-readable form.

The initial schema focus is the Certification Package and its generated representations. The Operations Toolkit supports this structure by generating and validating repository-based artifact sets without hosting a public service or replacing certification judgment.

Standards define expectations. Methodology defines the process. Certifier executes the workflow. Schema preserves the result in forms that people, repositories, and future systems can verify.
Schemas let certification records endure beyond the page that first published them.
