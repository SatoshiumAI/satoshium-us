Certifier · Schema

Schema

Schema defines the structured, machine-readable record format used by Satoshium Certifier. It allows certification records to remain consistent, portable, searchable, and interoperable.

The schema layer supports certification records, reports, receipts, evidence references, Registry entries, Anchor references, and future attestation records.

Certification Record Schema

The core schema defines structured fields for certification targets, classes, statuses, lifecycle states, standards, evidence, findings, outputs, integrity references, and history.

Core Schema

Machine Readability

Schema allows Certifier records to be validated, indexed, exchanged, preserved, and read by future software systems.

Structured

Interoperability

Shared schema conventions allow Certifier records to connect with Registry, Chronicle, Anchor, Beacon, Attestor, Navigator, and other Satoshium subsystems.

Connected

Versioning

Schemas should be versioned as Certifier evolves so that historical certification records remain understandable even when newer schema versions are introduced.

Versioned

Schema Role

Schema is the structural layer of Certifier. Documentation explains the system, reports preserve reasoning, receipts summarize outcomes, and schema gives certification records a durable machine-readable form.

The initial schema focus is certification-schema.json. Future schema files may define receipts, reports, evidence records, registry entries, Anchor references, and attestations.
Schemas allow trust records to be understood by people and machines.
