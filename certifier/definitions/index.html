Certifier · Definitions

Definitions

Definitions establish the shared vocabulary used by Satoshium Certifier as the Suite’s operational certification implementation. They keep certification records, reports, receipts, evidence references, schemas, and Suite integrations clear and consistent over time.

Suite Standards define the expectations. Suite Methodology defines the process. Certifier applies those foundations through certification packages, generated artifacts, and Suite-ready references.

Suite Standards → Suite Methodology → Certifier Schema →

Certification Package

The Certification Package is Certifier's canonical operational record. It preserves the Certification Subject, Profile, Scope, Evidence inventory, applicable Suite Standards, applicable Suite Methodology, evaluation, certification decision, generated artifacts, and certification history.

Canonical Object

Generated Artifacts

Generated artifacts are produced from the Certification Package and include the Certification Process Report (SCPR), Certification Receipt (SCR), Certified Record (SCRD HTML), Certified Record (SCRD JSON), and Suite-ready references generated during certification.

Derived Outputs

Suite Standards

Suite Standards define the expectations, evidence requirements, terminology, governance principles, schema expectations, and interoperability rules applied across certification activity.

Governing Layer

Suite Methodology

Suite Methodology defines the repeatable process used to conduct certification reviews, including lifecycle, workflow, evidence requirements, evaluation criteria, decision process, and schema logic.

Process Layer

Evidence Record

An Evidence Record preserves factual material supporting certification, including URLs, screenshots, reports, hashes, notes, supporting documentation, evidence mappings, and other review artifacts referenced during evaluation.

SEV Support

Suite Reference Objects

Suite reference objects prepare certification outputs for cataloging, preservation, integrity, discovery, verification, and orchestration across Registry, Chronicle, Anchor, Beacon, Attestor, and Navigator.

Interoperability

Core Term Map

  • SCPKG: Certification Package; the canonical source record for a certification.
  • SCPR: Satoshium Certification Process Report; the detailed report generated from the package.
  • SCR: Satoshium Certification Receipt; the concise public verification summary.
  • SCRD: Satoshium Certified Record; the canonical Certified Record represented as HTML and JSON.
  • SEV: Satoshium Evidence Record; preserved evidence supporting certification review.
  • SREG: Satoshium Registry Entry; the catalog reference prepared for Registry discovery.
  • SCHR: Satoshium Chronicle Record; the historical preservation reference.
  • ANCH: Anchor Reference; the integrity and preservation reference.
  • SATR: Satoshium Attestation Record; the verification-support reference.

Definitions Role

Definitions are Certifier's canonical language layer. They establish shared meaning for Certification Subjects, Certification Packages, generated artifacts, Suite references, and downstream integrations so every certification record is interpreted consistently across the Satoshium Suite.

As the Satoshium ecosystem expands, this page should preserve Certifier terminology while staying aligned with Suite-wide standards, methodology, schema, governance, and interoperability language.

Certification Subject

A Certification Subject is the operational object selected for certification. It becomes the focus of a Certification Package after Profile, Scope, and Evidence have been defined under the governing Suite Standards and Suite Methodology.
