# Registry References

This directory contains Registry-related records, references, indexes, and supporting materials generated by or associated with the Satoshium Certifier framework.

The Registry directory serves as the connection point between Certifier and the future Satoshium Registry subsystem.

While Certifier evaluates and certifies targets, Registry catalogs and organizes those certification records for discovery, reference, and long-term management.

---

# Purpose

The purpose of the Registry directory is to preserve information that may eventually be transferred, synchronized, or integrated with Registry.

Examples include:

* Registry-ready records
* Certification indexes
* Record catalogs
* Registry references
* Registry exports
* Registry metadata
* Future Registry integration artifacts

The directory serves as a bridge between certification and discoverability.

---

# Registry Philosophy

Certifier answers:

> Was this reviewed?

Registry answers:

> What certified records exist?

These are different but complementary functions.

Certifier focuses on:

* Review
* Evidence
* Determinations
* Certification

Registry focuses on:

* Discovery
* Cataloging
* Organization
* Reference

Together they create a complete trust ecosystem.

---

# Relationship to Certifier

Certifier produces records.

Registry catalogs records.

Example:

```text id="v8jz3s"
Certification Target
        ↓

        ↓

```

Registry does not replace certification records.

Registry helps users find them.

# Registry Entry Concept

A Registry Entry serves as a discoverable summary of a certified record.

A Registry Entry may contain:

* Registry Identifier
* Certification Record Identifier
* Certification Receipt Identifier
* Certification Report Identifier
* Target Name
* Target Type
* Certification Class
* Determination Status
* Certification Date
* Reference Links

Registry Entries should remain concise while providing pathways to supporting documentation.

# Registry Identifier Standard

Recommended Registry identifier format:

```text id="0shg71"
SREG-YYYY-NNNNNN
```

Where:

```text id="rz91zq"
SREG
=
Satoshium Registry Entry

YYYY
=
Year

NNNNNN
=
Sequential Identifier
```

Example:

```text id="zlw8kx"
SREG-2026-000001
```
